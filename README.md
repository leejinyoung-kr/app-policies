# app-policies

개인용 앱의 소개 · 개인정보처리방침 페이지 (GitHub Pages). Google OAuth 동의 화면을 프로덕션으로 게시할 때 홈페이지 · 개인정보처리방침 링크가 필요해서 둔다.

- 주소: `https://leejinyoung-kr.github.io/app-policies/<앱>/` · `.../<앱>/privacy.html`
- Google Cloud 승인된 도메인은 `leejinyoung-kr.github.io` 하나로 모든 앱이 같이 쓴다
- 새 앱: 폴더를 하나 만들고 루트 `index.html` 목록에 한 줄 추가

| 앱 | 쓰는 곳 |
| --- | --- |
| `safe-box/` | SafeBox 서버의 Google Drive 백업 (`drive.file`) |
